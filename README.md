# 网络服务订阅商店机器人（中文版）

一个基于 **pyTelegramBotAPI + SQLite** 的 Telegram 订阅销售机器人。支持套餐售卖、免费测试账号、钱包余额、卡转账回执审核、邀请返利、代理分销和完整的管理员后台。

> 由 **培哥** 制作并维护。

## 功能特性

**用户端**
- 入门流程：强制加入频道 → 接受使用条款 → 主菜单。
- 🛒 购买套餐：支持两种付款方式
  - 💳 卡转账：显示收款卡 → 上传回执图 → 管理员审核发货
  - 🏦 钱包支付：余额充足时即时扣款并自动发货
- 🔑 测试账号：普通用户限领 1 次，代理每天可领 1 个。
- 🛍️ 我的服务：查看已购服务与连接密钥。
- 🏦 钱包充值：输入金额 → 转账 → 上传回执 → 审核到账。
- 👥 邀请返利：专属邀请链接，被邀请人接受条款后奖励推荐人。
- 🙋‍♀️ 申请代理：升级后享 9 折与每日测试额度。
- ☎️ 客服：留言转发给管理员。

**管理端**
- 📦 库存管理：按套餐/测试分别批量录入与清理配置。
- 📊 统计：用户数、代理数、剩余库存、已售服务、用户余额总额。
- 🛠️ 用户高级管理：查询、增减余额、封禁/解封、授予/取消代理、全员充值/扣款、清理僵尸用户、管理员增删、临时锁定机器人、手动设置推荐人。
- ⚙️ 通用设置：修改收款卡、新增/删除套餐。
- 📢 群发消息。

## 安装与运行

```bash
pip install pyTelegramBotAPI
python bot.py
```

## 配置

编辑 `bot.py` 顶部的配置项：

| 常量 | 说明 |
|------|------|
| `API_TOKEN` | BotFather 的机器人 Token |
| `OWNER_ID` | 拥有者（超级管理员）的数字 ID |
| `CHANNEL_ID` | 强制加入的频道（带 @），留空则不强制 |
| `DB_NAME` | SQLite 数据库文件名 |
| `REFERRAL_BONUS` | 每成功邀请一人的奖励金额 |
| `AGENT_DISCOUNT` | 代理折扣（0.9 = 九折） |
| `DEFAULT_CARD_NUMBER` / `DEFAULT_CARD_NAME` | 收款卡初始值（之后可在后台修改并持久化） |

## 稳健性与安全设计

- **交易原子性**：发货与扣款在同一事务（`BEGIN IMMEDIATE`）内完成，避免「同一个配置发给两个人」或「扣了钱没发货」。
- **余额不会为负**：扣款使用 `MAX(balance + ?, 0)`，防止出现负余额。
- **权限校验前置**：所有管理员回调按前缀统一鉴权，非管理员一律拒绝。
- **防绕过入口**：机器人锁定、未加入频道、未接受条款时，普通消息也会被拦截（不仅 `/start`）。
- **邀请奖励防刷**：仅首次接受条款才发奖励，重复点击无效。
- **配置持久化**：收款卡与锁定状态存入数据库，重启不丢失。
- **数据库连接管理**：统一入口 + 自动关闭 + 写操作加锁 + WAL 模式，避免连接泄漏与并发写冲突。
- **输入校验**：所有管理员输入均校验数字与格式，错误时给出明确提示。
- **发送容错**：用户拉黑机器人等异常被捕获并记日志，不会中断批量任务。

## 已知限制与建议

- **人工核账**：充值与转账购买靠管理员肉眼核对回执图，存在假回执风险。
- **SQLite 单机**：适合中小规模；高并发场景建议迁移到 PostgreSQL/MySQL。
- **状态存内存**：`user_states` 在内存中，重启后待输入状态会丢失（不影响已成交数据）。
- **无退款流程**：删除服务不会自动退款，需管理员手动调整余额。
- **合规提示**：请仅用于合法商品与服务销售，遵守所在地区的法律法规。
